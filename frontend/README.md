# Frontend

Thư mục dành cho giao diện website E104A-H2.

Yêu cầu:
- Responsive trên máy tính và điện thoại.
- Không dùng iframe để nhúng Apps Script.
- Không chứa khóa bí mật hoặc thông tin đăng nhập dịch vụ.
- Giữ nguyên thứ tự câu hỏi và phương án ở chế độ luyện tập.

Khung giao diện sẽ được bổ sung sau khi chốt cơ chế tích hợp API an toàn.
